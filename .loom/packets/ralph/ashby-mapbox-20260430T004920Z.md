# Task For This Iteration

Build, in one bounded slice:

1. **`src/dream_job_radar/extractors/ashby.py`** — mirror the
   Greenhouse extractor shape:
   - `ASHBY_API = "https://api.ashbyhq.com/posting-api/job-board/{slug}"`.
   - `USER_AGENT = "dream-job-radar/0.1"`.
   - `TITLE_KEYWORDS = ("data", "engineer", "gis", "geospatial")`.
   - `DEFAULT_BOARDS = ("Mapbox",)` — case-sensitive; do not lowercase.
   - `_title_matches(title)` — same lowercase substring helper.
   - `_fetch_jobs(slug)` — GET, `raise_for_status()`, parse JSON,
     return `payload["jobs"]` (raise `ValueError` if not a list).
   - `_normalize(job, slug, fetched_at)` — produce a flat dict with
     these fields:
     - `company`: slug verbatim (preserve case)
     - `source_kind`: `"ashby"`
     - `ats_slug`: slug verbatim
     - `role_id`: `str(job["id"])` — Ashby ids are already strings
     - `title`: `job.get("title", "")`
     - `url`: `job.get("jobUrl", "")`
     - `location`: `job.get("location") or (job.get("secondaryLocations") or [None])[0]` — single string fallback to first secondary, else `None`
     - `departments`: `[job["department"]]` if `department` is truthy
       else `[]` — wrap to match the Greenhouse shape (list of str)
     - `posted_at`: `job.get("publishedAt", "")`
     - `fetched_at`: ISO timestamp at run start
     - `raw_json`: `json.dumps(job, sort_keys=True)`
   - `board_resource(slug)` — returns a `@dlt.resource(name=slug,
     write_disposition="append")` factory. Inside the resource:
     filter `isListed == True` first (defensive against drafts),
     then apply title-keyword filter, then yield normalized record.
   - `board_resources(boards: tuple[str, ...] = DEFAULT_BOARDS)` —
     return `[board_resource(slug)() for slug in boards]`.

2. **`src/dream_job_radar/pipelines/ashby.py`** — mirror
   `pipelines/radar.py` (the current Greenhouse pipeline):
   - `PIPELINE_NAME = "dream_job_radar"`.
   - `SOURCE_KIND = "ashby"`.
   - `DATASET_NAME = SOURCE_KIND`.
   - `_r2_destination()` configured with
     `bucket_url = f"s3://{R2_BUCKET}/raw"`,
     `endpoint_url`, AWS-style credentials, `region_name="auto"`,
