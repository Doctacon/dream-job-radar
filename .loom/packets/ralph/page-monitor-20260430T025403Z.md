# Task For This Iteration

Build, in one bounded slice:

1. **`src/dream_job_radar/extractors/page.py`** — page-monitor
   resource factory with two parser strategies:
   - `USER_AGENT = "dream-job-radar/0.1"`.
   - `TITLE_KEYWORDS = ("data", "engineer", "gis", "geospatial")`.
   - `class SiteSpec(NamedTuple): slug: str; url: str; parser_kind:
     str` (`parser_kind` is a literal — `"gusto_board"` or
     `"felt_careers"`).
   - `DEFAULT_SITES = (
        SiteSpec(slug="regrid",
                 url="https://jobs.gusto.com/boards/regrid-map-your-future-c265c805-0902-4628-bd27-d013fdcfb5bc",
                 parser_kind="gusto_board"),
        SiteSpec(slug="felt",
                 url="https://felt.com/careers",
                 parser_kind="felt_careers"),
     )`.
   - `_title_matches(title)` — same lowercase substring helper.
   - `_parse_gusto_board(html, slug)` — regex-extract role records
     using:
     ```python
     GUSTO_ROW_RE = re.compile(
         r'<a class="block hover:bg-gray-50" href="(/postings/[^"]+)".*?'
         r'<h3 class="text-lg">([^<]+)</h3>',
         re.DOTALL,
     )
     ```
     For each match, derive `role_id` via UUID-tail regex
     `r'-([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})$'`
     against the URL slug. If the UUID extraction fails, fall back
     to the entire posting slug (and self-flag in self-review).
     Build `url = "https://jobs.gusto.com" + posting_path`.
   - `_parse_felt_careers(html, slug)` — regex-extract role titles
     using:
     ```python
     FELT_ROW_RE = re.compile(r'<div class="h4 careers">([^<]+)</div>')
     ```
     For each match, derive `role_id =
     hashlib.sha1((slug + ":" + title).encode("utf-8")).hexdigest()[:16]`.
     Use the careers page URL itself as `url` (Felt has no per-role
     URL).
   - `_normalize(role_data, spec, fetched_at)` — produce the
     canonical row:
     - `company`: `spec.slug`
     - `source_kind`: `"page"`
     - `ats_slug`: `spec.slug`
     - `role_id`: from parser
     - `title`: from parser, stripped
     - `url`: from parser
     - `location`: `None` (parsers may add later)
     - `posted_at`: `""` (page monitor sources have no upstream
       posting date)
     - `fetched_at`: ISO timestamp at run start
     - `raw_json`: `json.dumps(role_data, sort_keys=True)`
   - `_fetch_page(url)` — GET with polite User-Agent, raise on
     non-200, return `resp.text`.
   - `site_resource(spec)` —
     `@dlt.resource(name=spec.slug, write_disposition="append")`.
     Inside:
     - print one structured line per encountered role indicating
       MATCH or skip (mirror `extractors/sitemap.py`'s log format).
     - dispatch to the right parser by `spec.parser_kind`. Raise
       `ValueError` on unknown parser_kind.
     - apply `_title_matches` to filter.
     - yield `_normalize(...)` for matches only.
   - `site_resources(specs=DEFAULT_SITES)` — list of resources, one
     per spec.
